# Worksheet: observations before conclusions

1. Record source filename/SHA256, synthetic versus authorized case, capture point, UTC window, address mapping, missing directions and truncation. State the asset's expected service and where that expectation came from.
2. Apply `icmp`, then separately `icmp.type == 8` and `icmp.type == 0`. Record original frames, sender/recipient, time, identifier, sequence and bytes. Compare requests across sequences and peers; match each reply without counting returned bytes as fresh independent content. Compare fixed versus changing request data and diagnostic alternatives.
3. Apply `icmpv6.type == 128` and `icmpv6.type == 129` separately. Record IPv6 endpoints, identifiers, sequence, data and direction. Do not reuse IPv4 type numbers or assume IPv4/IPv6 physical host equivalence.
4. Select frame34. Expand Internet Control Message Protocol and its embedded Internet Protocol/User Datagram Protocol details. Record outer type/code/endpoints and match its quoted 28-byte header to frame33. Distinguish quoted headers from new Echo data. State what the quote omits.
5. Compare `tcp.port == 8443` with `tcp.dstport == 8443`, checking both directions and SYN/SYNACK rather than using destination-only packets to assert the initiator. Assess `udp.port == 8443` and `udp.dstport == 8443` separately; do not merge transports because of a shared number.
6. Clear the filter. Statistics > Conversations > TCP: uncheck Limit to display filter for the whole-file comparison. Record endpoints/ports, packets, bytes, relative start and duration for streams0/1. Scroll horizontally to the time columns. Repeat with a stream filter and the checkbox checked; explain the changed scope.
7. Apply `tcp.stream == 0`, select a packet, Analyze > Follow > TCP Stream. Read both directions in ASCII, then close and return to packet timestamps. Record the initial automatic protocol label and the visible structure supporting or challenging it. Compare with stream1. Record that encryption or missing bytes in a real case could prevent these checks.
8. Decode As is conditional, not mandatory guesswork. If an actual label conflicts with visible structured requests/responses, record the original, test only a plausible supported dissector via Analyze > Decode As, compare several packets and both directions, then restore the original setting and verify restoration. If the automatic HTTP reading fits this fixture, write 'no alternative test warranted' with evidence. Do not manufacture a mislabel or claim an unperformed GUI action.
9. Write a bounded finding for each candidate: observation with exact frames/filter/bytes; inference clearly labeled; reasonable diagnostic/service explanation; evidence against it; missing process owner, service configuration or maintenance record; confidence; next useful action. Unmatched filters require checking capture scope before declaring absence. Repeat the worksheet on your own authorized capture and retain its separate source record.
