# Data dictionary and boundaries

`fixture-spec.json` is explicit synthetic version1 input. Events have UTC timestamp, kind and documentation-range endpoints. Echo events carry identifier, sequence and literal UTF8 data. TCP events carry source/destination ports, raw sequence/ACK, flags and literal payload. UDP has independent port fields and payload. An `icmp-error` event quotes the actual specified frame33 IPv4 header (20 bytes) plus UDP header (8 bytes), not its data. IPv6 Echo has type128/129 and its own checksum pseudoheader.

`practice.pcap` is Ethernet classic PCAP, 34 complete untruncated records, 2627 filesystem bytes, 2059 captured packet bytes; per-record headers add 544 bytes and the PCAP global header adds24. These are distinct units. Frames1–10: IPv4 Echo. Frames11–19: TCP8443 stream0. Frames20–28: TCP80 stream1. Frames29–30: UDP8443. Frames31–32: IPv6 Echo. Frame33: UDP33434. Frame34: IPv4 ICMP destination/port unreachable, quoting frame33 headers. The nested quoted UDP checksum cannot be fully checked without its omitted payload; a decoder 'unverified' here is not evidence of corrupt outer ICMP.

`decoded-fields.stdout.txt` is actual TShark4.4.0 tab-separated output with headers, payload hex and checksum statuses. `execution.json` binds actual command arguments and outputs. `verify.stdout.txt` is the separate byte verifier's result; `conversations.stdout.txt`, `follow-stream.stdout.txt`, and `error-details.stdout.txt` contain actual decoder measurements. Historical `all-frames*`, `capture-info*`, `ip-conversations*`, `protocol-hierarchy*`, `tcp-conversations*`, `malformed*` and `assembly-manifest.json` describe the old 30-frame subset only; they are not current acceptance evidence.

`native-*.png` plus native execution/review receipts are actual isolated native Linux GUI evidence with narrow roles. A GUI image confirms only its visible controls/values, not hidden fields or every workflow. The current inventory, not a historical manifest, lists final bytes. No Host literal was required by the lecture; this synthetic fixture uses `lab.example` and `health.example`.
