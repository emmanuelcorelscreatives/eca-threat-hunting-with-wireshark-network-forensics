# Setup

## Release resources

The reviewed lesson package must provide `worksheet.md`, `answer-guide.md`, and the course-owned blank workbook `practice/unified-evidence-timeline/unified-evidence-timeline.ods`. The workbook must have three sheets, the exact headers in `worksheet.md`, text-preserving timestamp and identifier cells, and no case rows. Its presence and validation are not claimed in this draft. Do not produce dependent visuals or exports until it is created and checked.

No case capture or log is required. The verified DNS-baseline fixture is unrelated and is not used.

## Environment and handling

Use Windows 11, Wireshark 4.4.0, English menus, light theme, and LibreOffice Calc 24.2. Keep the blank template unchanged; save filled work separately. Preserve authorized originals and identify working or adjusted copies.

With an authorized capture, first document its collection point and window. Open an appropriate working copy. Check `Statistics > Capture File Properties`; then use `View > Time Display Format` and absolute date and time. In an empty workspace, Capture File Properties is unavailable. Display format does not validate capture-clock accuracy.
