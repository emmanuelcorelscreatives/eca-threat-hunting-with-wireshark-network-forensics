# DNS triage fields

Each worksheet row is one transaction. `candidate` is D, F or U. `source_file` is the capture filename. `query_frame` and `response_frame` are original file frame numbers, never filtered row positions. `query_time_epoch` and `response_time_epoch` are separate UTC Unix-second timestamps. `query_source` is the source IP of the QUERY; `query_destination` is the resolver. A response reverses these addresses and UDP ports. Match DNS ID AND reverse address/port tuple, name and type; ID alone is insufficient.

`query_name` and `query_type` come from Questions. `response_code` records the received DNS rcode, with 0 meaning no DNS error and 3 meaning NXDOMAIN. `answer` records the applicable A, PTR, SRV or TXT fields; NOERROR is not synonymous with an A answer. Missing response values stay blank, never zero or NXDOMAIN. `later_frame` and `later_time` cite separately found traffic to a returned address; blank means none observed in this limited fixture, never no real-world activity. `statement_class` is observed, inferred or unknown. A statement about fixture packets can be observed; invented card notes cannot establish an owner, process or authorization. `hypothesis` explains possible causes. `follow_up` names the narrow extra record and relevant time window.
