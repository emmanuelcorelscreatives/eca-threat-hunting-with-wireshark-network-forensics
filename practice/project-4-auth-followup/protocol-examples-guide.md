# Separate synthetic protocol examples

Open protocol-examples.pcap separately. This is not the primary23-frame fixture or the saved lesson case. The complete source is build_protocol_examples.py; protocol-examples-spec.json is an output summary. No live network calls, keys, tickets, hashes, passwords or real credential responses were used. Actual TShark4.4.0 decoding is in protocol-decoded-fields.tsv and protocol-details.txt.

Frames1/2 and3/4 are designed UDP88 AS-REQ(message10) / KRB-ERROR(message30) pairs from192.0.2.10 to fictional DC-LAB192.0.2.40 and back. Inspect client svc-lab, realm EXAMPLE.TEST and krbtgt server principal; request and response UDP port pairs distinguish exchanges. Error24/0x18 at10.500UTC and25/0x19 at10.700UTC are designed to align with EV01/EV02 fields, not actual KDC authentication. Requests omit PA-DATA; these are decoder-readable teaching messages, not a production reproduction or proof that a real KDC would return these codes to these exact requests. Error24 is invalid pre-authentication; error25 requests additional pre-authentication. Do not count both as bad-password failures.

Frames5–14 form one TCP80 stream to APP-B. HTTP carries NTLMSSP Type1 at8, Type2 challenge at9, Type3 at10; frame10 names fictional svc-lab, EXAMPLE, LAB-CLIENT. The Type2 challenge is zero teaching bytes, LM/NT credential response lengths are0. This is deliberately non-authenticating, not usable account material or a validated login. HTTP401 at11 rejects after Type3. The message sequence is present, but accepted authentication is not. Visible username is not actor identity. EV04's source/account/recording host/failure context is consistent as a tentative designed relationship, not a proven packet-to-event join or causal relationship. EV03/4776 lacks destination; do not use this TCP80 stream to invent one.

Two PCAPs and the event CSV are separate sources; always include the source filename with frame numbers. Their timestamps are designed values. No production clock accuracy, capture completeness or real host execution is claimed.
