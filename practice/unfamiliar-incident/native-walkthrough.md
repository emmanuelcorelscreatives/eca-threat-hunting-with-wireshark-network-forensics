# Wireshark workflow

Open a working copy using File → Open; this is offline, not collection. Set View → Time Display Format → UTC Date and Time of Day when available and record the displayed time mode. Statistics → Capture File Properties reports source boundaries; classic PCAP lacks interface/drop metadata. In Statistics open Protocol Hierarchy, Endpoints, Conversations (TCP tab) and I/O Graphs. Compare all traffic first. Directional byte counters include captured framing and transport overhead; they are not sensitive-file byte counts.

Enter each expression from actual-verification.json in the display filter bar, press Enter and compare frame numbers with its selections. The native PNGs show actual filtered rows for this supplied file, not every required analyst action. Perform the additional Statistics and Follow tasks yourself and document your observations. Select the first payload in a relevant TCP stream; Analyze → Follow → TCP Stream exposes only the authored placeholder. Close it, clear its stream filter and restore the wider view. Click an I/O Graph time region and inspect the corresponding original packets; a graph alone is insufficient evidence. Recheck cited frame numbers against the unchanged original. Linux4.4 native evidence does not establish Windows behavior.
