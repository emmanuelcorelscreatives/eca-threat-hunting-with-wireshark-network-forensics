3. **Shared transport and either port position.** Place both tests *outside* the complete directional group and apply `((ip.src == 192.0.2.10 && ip.dst == 198.51.100.20) || (ip.src == 198.51.100.20 && ip.dst == 192.0.2.10)) && (tcp) && (tcp.port == 443)`. 4. **Inclusive start, exclusive end; destination-only contrast.** Append `&& frame.time >= "2026-01-01 12:00:00" && frame.time < "2026-01-01 12:05:00"` *outside* the pair group.
