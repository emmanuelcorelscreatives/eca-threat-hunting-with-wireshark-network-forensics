# Project 6: The Internal Hop — supplemental offline lab

This independently authored synthetic practice supplies two executable captures and supporting scenario records. It is separate from the unavailable historical Project 6 case pack. No historical incident, real authentication, host execution, operator pivot or authorization finding is claimed. The original lesson remains unchanged.

Use an isolated practice machine. Install Wireshark from https://www.wireshark.org/download.html and extract the entire kit. No live capture, network connection, credentials or production data are needed. Open `OP-A-workstation-edge.pcap` and `OP-B-server-segment.pcap` separately using File → Open. Preserve each source's frame numbers. Classic PCAP lacks interface description and operating-system metadata; record those fields as unavailable. Source file first/last packet times differ from the planned sensor windows in `sensor-coverage.csv`.

The kit includes worksheet and answer guide, four authored CSVs, this setup, data dictionary, two PCAPs, `offline-builder.py`, `execution.json`, current inventory, and actual per-source CLI dissection, Conversations, properties and malformed checks. The tiny captures each contain an opening TCP exchange followed by application identification and responses; neither contains FIN/RST closure. They are intentionally short and do not establish long session continuity.

To reproduce offline with Python 3, run `python offline-builder.py rebuilt` from the extracted kit directory, choosing a fresh destination. Both resulting files must match the distributed SHA-256 values in `execution.json`. The builder refuses any destination already containing either target capture. It uses only Python's standard library, creates no network sockets, and does not alter the original files. Optional checks: `capinfos OP-A-workstation-edge.pcap`, `tshark -r OP-A-workstation-edge.pcap -V`; repeat for OP-B. Windows users can use `py -3` instead of `python`.

An account label does not identify a person. WKS-07 is 192.0.2.23, SRV-A is 198.51.100.14. The assignment of 198.51.100.15 expires before the SSH event; its event-time asset is unresolved.

In Wireshark select UTC date/time display, check Capture File Properties and Statistics → Conversations for each source, select the TCP tab, and record direction, packet counts, duration and start. Filter `smb2`, `ssh`, `rdp || rdpudp`, and `tcp.port == 5985 || tcp.port == 5986`. A familiar port is only a candidate. Select a relevant packet and choose Analyze → Follow → TCP Stream; close the stream view and clear its display filter before examining nearby traffic. Opening identification is not authentication or execution. Missing filter hits do not clear systems outside sensor coverage.
