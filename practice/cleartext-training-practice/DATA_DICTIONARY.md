# Data dictionary and provenance

PCAP is classic little-endian microsecond format, Ethernet/IPv4/TCP, no capture truncation. Endpoints and UTC times are chosen synthetic fixture design, not historical measurements. Frame numbers are original one-based record order; tcp.stream is Wireshark4.4.0 conversation numbering. Client ports41000/41001 select two FTP conversations;42000/42001 select HTTP credential versus marker conversations. Payloads are fictional; the builder necessarily contains them and must be handled as original lab content. Only command names and frame/stream/endpoints appear in redacted exports. Stdout uses native version output and stderr may include harmless tool startup messages. Native private GUI shots, if referenced by an approval receipt, are retained separately rather than distributed; they are not redacted discussion artwork. No independent approval of a video scene or render is implied.
