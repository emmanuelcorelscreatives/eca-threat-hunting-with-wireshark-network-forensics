# Analyst worksheet

Write packet observations separately from interpretations and synthetic context.

1. Inventory both source files: SHA256, provenance, collection point (scenario assertion or unknown), first/last packet UTC times, captured and displayed count after clear, packet count under restrictive filter, clock uncertainty, capture restrictions and known collection interruptions. Do file bounds prove uninterrupted monitoring? Does the space between packet bounds measure outage duration?
2. Candidate lead: before.pcap frames1–2. Describe each endpoint/port/direction/time, observed payload identifier and local frame. Propose a harmless alternative. Match the independent activity record's owner, source, peer, ports, job and time; is it sufficient for the scenario only? Does the same label alone suffice? Which provisional incident link and scope inclusion change, and which packet observations remain?
3. Candidate continuity: before.pcap frames3–4 and after.pcap frames1–2. Give precise file-local citations and observations. Which hypothetical handoff cannot be confirmed? Can either capture prove activity during the interruption, execution, compromise, or authorization? Distinguish recorded packet bounds from the supplied collector interruption interval. Consider the ±0.250s collector and ±2s activity-record uncertainties before comparing events.
4. Control experiment: filter before.pcap to `ip.addr == 192.0.2.10`, then clear it. Record displayed counts and Conversations scope checkbox. Did collection change? Can a display filter restore uncaptured traffic? Compare with the actual synthetic collector interruption record.
5. Revise provisional scenario scope and confidence separately. Exclude the supported harmless link; retain observations B/C but mark their connection unresolved. Is any host proved affected? What if the activity record were missing or only named a label? What if new host evidence independently supported the probe host? Never remove that independent concern merely because this link is harmless.
6. Request targeted evidence separately for continuity, execution and lead ownership: specify host/peer, direction, UTC interval, collection point/clock normalization and required source. Explain what each could and could not establish.
7. Complete case-analysis-template.md for the actual Project7 branch. If actual packets or records were never supplied, what is your conditional outcome? Do not substitute these synthetic files as historical evidence.
