# Provenance and fields

All IPs are RFC5737 documentation addresses, all payloads explicitly TRAINING. PCAP bytes are constructed offline from disclosed version1 JSON events, using Ethernet/IPv4/UDP with valid checksums; no packets were sent. UTC timestamps are deterministic scenario values, not acquisition times. before-spec.json/after-spec.json identify synthetic=true. The builder uses Python standard library only and exclusive-create output.

capture-register.csv: file, synthetic scenario collection point and packet bounds/counts. collection-records.csv: scenario collector plan/filter/clock and explicit synthetic interruption, distinct from file time bounds. approved-activity.csv: independent invented business/job context, exact tuple and authorized window; not packet-derived or real authorization. asset-records.csv: invented fixed address mapping validity; no proof of real compromise. execution-proof.json contains actual tool execution on these files. Native images contain actual Linux Wireshark rendered synthetic packets; no incident verdict is inferred from them. Current inventory/review receipts bind exact bytes. Sources under this package do not replace missing Project7 evidence.
