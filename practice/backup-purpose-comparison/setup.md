# Setup and practical workflow

Use only this synthetic practice.pcap or an authorized working copy. Unzip the complete kit into a new local directory. Install Python 3 and Wireshark/TShark using your organization's approved process. From the kit directory verify the supplied capture using `tshark -r practice.pcap -q -z conv,tcp`. For a fresh deterministic rebuild use `python offline-builder.py --spec synthetic-transfer-spec.json --output rebuilt-practice.pcap`. The builder refuses an existing output; choose a new filename rather than deleting source evidence. It uses only Python's standard library and sends no network traffic. The delivered rebuild receipt records actual execution, exact byte equality and overwrite refusal. Compare the SHA-256 of your new file with the receipt. On Windows use `Get-FileHash rebuilt-practice.pcap -Algorithm SHA256`; on Linux use `sha256sum rebuilt-practice.pcap`.

Open practice.pcap in Wireshark. Select View → Time Display Format → UTC Date and Time of Day. Open Statistics → Conversations → TCP. Record the pair, ports, start, duration, packets and bytes by direction. If using `ip.addr == 192.0.2.10 && ip.addr == 198.51.100.40 && tcp.port == 9000`, explicitly record whether Limit to display filter is checked. This fixture has only one conversation, so the broad filter does not create a different count; that equality is not proof of checkbox state. Inspect frames 1–3, 4, 10 and 12–15 in Packet Details: expand TCP, compare flags, timestamps and tcp.len. Select frame 4, then Analyze → Follow → TCP Stream. Inspect both directions; close Follow and restore the prior display filter. Follow cannot decrypt encrypted traffic.

Complete the matrix before reading the answer. A learner may repeat these checks on a separately authorized capture, recording its actual host/peer/window/capture point and minimizing owner requests.
