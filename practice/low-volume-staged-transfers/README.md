# Look for Low-Volume and Staged Transfers

Start with setup.md, complete worksheet.md, and compare with answer-guide.md. All files are supplied together in this offline kit. The saved lecture and instructor are unchanged.

Two complementary exercises are included: practice.pcap is a deterministic synthetic 34-frame documentation-address case with an eight-hour file span; actual-tls-staging.pcap is a real, harmless loopback TLS collection from the author lab, paired with actual-host-file-events.json. They are separate captures with separate identities. Neither is a historical incident or a learner-owned capture. The host log permits a bounded file-staging comparison in the second exercise. Packet timing alone never establishes process identity, destination approval, off-hours activity, collection completeness or data loss.

Current hashes and byte sizes are in current-kit-inventory.json. historical-execution-proof.json and assembly-manifest.json describe older snapshots and are retained as history, not the inventory of current prose. The actual collection code is delivered for inspection, not required to run. Offline packet analysis requires no network. Private keys are omitted; encrypted content remains encrypted in Wireshark.
