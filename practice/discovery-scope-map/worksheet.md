# Discovery scope worksheet
1. Record the source SHA, declared window, actual first/last timestamps, hypothetical observation point, covered path and unconfirmed segment separately. Keep the original unchanged.
2. Apply exactly `tcp.flags.syn == 1 && tcp.flags.ack == 0`. This shows initial SYNs including retry, hides replies and does not measure full scope. Clear it before inspecting exchanges.
3. Use Statistics > Endpoints (IPv4 and TCP tabs) and Conversations. Check Limit to display filter before interpreting counts; record whether checked. Verify the initiator in nearby packet sequences, not merely a conversation row. If timestamps are hidden, widen or scroll actual columns. Use Statistics > I/O Graphs at 1 second then 100 milliseconds with the SYN filter; bins count matching packets, not successful connections; return to packet sequences.
4. In Calc, create one row per initiator, target, transport and destination port. Fill every template field; combine repeated SYN in its existing row. Cite first/last attempts and every response frame. A port suggests a service, not a proven application.
5. Inspect frames 1–3 for handshake; 4–5 for reset; 6–7 for retry; 8–9 for gateway ICMP quotation; 10–11 for UDP bytes; 12 for silence; 13–14 for partial handshake. In packet details inspect outer ICMP sender, type3/code1 and quoted UDP destination. A gateway report is not a target response. No reply captured is not host down; UDP has no TCP handshake.
6. Compare with synthetic asset-inventory.csv, count initiators, distinct attempted targets and grouped rows within the window. Do not treat the uncovered segment as quiet. Add row-specific coverage limits and leave process/device/approval unknown.
7. Submit filled matrix, scope-statement.md (Observed / Interpretation / Still unknown) and endpoint-context-request.md for exact window, destinations, ports, process/parent, clock/log coverage, address/NAT mapping and approval. Missing records do not clear a host. Preserve discovery, approved management and network-fault alternatives.
8. Reopen all cited frames with filter cleared; verify replies were not hidden. This exercise supplies a worked author fixture, not evidence that a learner performed an own-capture task. For an authorized learner-owned offline or lab capture, repeat source preservation, window/path assessment and row citations using that capture's real values; never transfer this key's results.
