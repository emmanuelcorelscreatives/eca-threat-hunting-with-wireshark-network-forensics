# Data dictionary and provenance

sensor-a-spec.json and sensor-b-spec.json are explicit version-1 synthetic inputs, using documentation IPv4 ranges and reserved DNS names. tools/offline_builder.py writes deterministic Ethernet/IPv4/UDP/TCP packets offline, validates input bounds and refuses existing outputs. It transmits nothing. captures/ contains two preserved PCAP sources and a mergecap-generated PCAPNG derivative. The original one-source practice.pcap has become captures/sensor-a.pcap byte-for-byte; the delivered sensor-a hash matches the earlier limited fixture.

manifest.json records each source identifier, source path, SHA-256, synthetic capture perspective, measured packet count and first/last epoch microsecond timestamp. Its derivative entry records the 26 retained packets. These are not real sensor logs. Authored perspective and scenario correspondence do not establish actual clock offset or independent real collection.

mapping/merged-frames.csv columns are derivative_frame (1-based in merged.pcapng), interface_id (actual EPB interface), timestamp_microseconds (captured epoch), packet_sha256 (exact captured bytes), source_candidates (all source/frame matches by exact bytes and timestamp), verified_source_frame (only when unique), and status. No equal-frame-number inference is used. Every row is recomputed by the read-only verifier. Two packet streams with indistinguishable bytes/timestamps would remain unresolved rather than being arbitrarily assigned.

automation/sensor-{a,b}-{all,dns,http,response}.tsv are actual field exports. Rows are packets, not endpoint or conversation summaries. Fields include source-local frame.number, epoch/UTC time, visible peers, IPv4 ID, stream, ports, request method, response code, repeated cookies and DNS name. Repeated values use |; missing fields use empty cells. The first-cookie controls intentionally retain only one occurrence. export-settings.json states the actual profile, filters and value handling. command-transcript.json lists actual commands and output files; expected nonzero overwrite refusals are retained. Warnings about running as root concern author execution and are not captured packet contents.

*-repeat.stdout.txt are independent invocations on unchanged sources. *-stats-* and *-endpoints-* use their own counted units and statistic filter. *-readlimit-one* illustrates read-before-filter behavior. *-malformed* has no flagged frames; that alone is not a universal capture-quality guarantee. native-v2/ contains actual screenshots and host/tool/profile receipts, with independent review recorded separately. manifest.sha256 covers delivered files except itself; supplemental review and public publication receipts are outside the kit to avoid circular hashes.

hypothetical-claims.csv preserves H1–H4 as originally authored hypotheses. It is not an actual automated timeline. Use the supplied actual TSVs for row-to-packet verification. The command transcript, manifests and packet observations remain distinct from untested explanations.
