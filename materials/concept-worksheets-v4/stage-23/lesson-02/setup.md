# Setup

**Downloadable lesson resources:** `worksheet.md`, `answer-guide.md`, and `setup.md`. The synthetic decision exercise needs no capture or prior report. A completed-case worksheet instead requires authorization, an already-checked previous report, a preserved original capture, and an approved offline working copy; none is supplied for this concept lesson.

For the file walkthrough, use Wireshark on an authorized isolated practice workstation. Do not capture live traffic, contact a destination, or use private production data or credentials.

**Optional supplemental download:** The verified public repository, https://github.com/emmanuelcorelscreatives/eca-threat-hunting-with-wireshark-network-forensics, contains `practice/dns-baseline/README.md` and its source-described six-packet synthetic DNS fixture. Consult the README for the capture filename. Use an approved offline copy to practise File > Open and Capture File Properties. This DNS fixture cannot establish repeated TCP connections. No fixture metadata or packet result was independently checked here.
