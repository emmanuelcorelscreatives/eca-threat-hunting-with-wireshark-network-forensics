# Files and register fields

`practice.pcap` is the original 23-frame synthetic Ethernet/IPv4/TCP/HTTP capture. `fixture-spec.json` and identical `executed-fixture-spec.json` define the ordered UTC events. `offline-builder.py` builds it offline from explicit synthetic input and refuses an existing output. `builder-execution.json` records fresh actual rebuild/refusal/invalid-input checks. `fixture-manifest.json` binds the current capture hash and measured controls while marking observation point/window as authored.

`inert-training-object.txt` is 35 ASCII bytes including both LF line endings. `verified-export.txt` is an identical copy of the actual GUI-saved export. The native PNGs show HTTP filtering, selected exporter row, packet7 jump, reassembly/text details and actual Windows PowerShell hashing. Independent receipts approve only their assigned native evidence roles. `windows-hash-receipt.json` and the transcript record the real Windows check of those saved bytes. Other `.stdout.txt`, `.stderr.txt` and execution JSON files retain actual local CLI output; the root-user warning on stderr is a runtime warning, not a failed dissection.

`artifact-register.csv` is a header-only learner template, not an already completed finding. Each row records `capture_id`, `capture_sha256`, `capture_window_utc`, `capture_point`, `known_gaps`; `request_frame`, `request_method`, `request_host`, `request_path`; `response_frame`, `response_status`, `content_type`, `pairing_reference`, `exporter_packet`, `source_frames`; `export_path`, `algorithm`, `export_sha256`; and `delivery_claim`, `execution_status`, `alternatives`, `confidence_limits`, `next_action`. Use actual observations, leave unsupported values empty and explain the gap. Quote cells containing commas. Export path and capture path denote different files.

`historical-assembly-manifest.json` preserves the earlier assembly's state/paths/hashes and is explicitly historical. `current-kit-inventory.json` binds all other currently delivered files, excluding its own hash to avoid recursion. The publication evidence binds the inventory envelope's exact bytes separately.
