# Data dictionary and provenance

practice.pcap is deterministic offline synthetic Ethernet/IPv4/TCP/HTTP traffic. fixture-spec.json defines literal event times, flags, sequence/acknowledgment values and payloads. build_capture.py uses standard-library serialization and validates documentation addresses; it sends no traffic. No dependencies beyond Python 3 are required.

actual-http.csv is actual two-pass TShark 4.4.0 output. frame.number identifies the PCAP frame; frame.time_epoch is seconds since Unix epoch in UTC; tcp.stream is a decoder conversation index. ip.src/ip.dst are packet endpoint addresses, not authenticated identities. http.request.method, http.host and http.request.uri describe a request. http.response.code and http.location describe a response and advertised target. http.content_length is the HTTP declared body length, not automatically the full original object size. http.content_range records a range in an original representation. http.request_in and http.response_in are optional decoder pairing references. http.file_data contains hexadecimal body bytes in this CSV. Empty fields mean absent/not decoded for that row, not proof that something never existed elsewhere.

redirect-chain-worksheet.csv is a blank learner artifact, not evidence. answer-guide.md gives checked controls. execution-proof.json records capture hash, builder reproducibility, actual decoder command and absence of matching malformed/checksum/loss frames under the recorded filters. actual-command-results.txt contains additional exact executed commands/results. README.md records authored coverage limits. All case roles and benign updater context are Academy design metadata, separate from packet observations. No host logs, credentials, malware, external data or capture from the learner's device are included.
