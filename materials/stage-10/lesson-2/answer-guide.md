# Measured answer guide

These controls are from actual TShark 4.4.0 decoding of the shipped synthetic PCAP, not a historical incident. See actual-http.csv for epoch timestamps and exact fields. Eight requests and eight responses occur in 88 frames, streams 0–7. The client is 192.0.2.10. Each stream contains one request and one response, with complete handshake and orderly close. The builder regenerated byte-identically; malformed, checksum-invalid and TCP loss/retransmission filters returned no frames. This is finite authored test coverage, not a guarantee about a real collection environment.

The first visible request is at 12:00:00.060 UTC. Corresponding request times increase by one second through 12:00:07.060 UTC; each response is 40 milliseconds later. Read absolute timestamps from actual-http.csv rather than treating display-relative times as UTC. Automatic request_in/response_in fields corroborate all eight pairs, including the 206 pair at frames 59 and 61 in stream 5. Verify the references against endpoints, request and response content and order.

The main observed sequence contains /start → /step → readme.txt across streams 0, 1 and 2. Follow Stream on stream 0 shows only the first proposal, so clearing the stream filter is essential. Location /step retains the original host; repeated Host fields can map to different authored server IPs here. A captured match demonstrates a follow-up request but cannot prove a user clicked or that an HTTP redirect caused it. No Referer is sent in the main sequence; absence does not prove direct navigation.

The updater comparison is labelled benign by Academy scenario design, not established by packet headers. Its 302 and subsequent cross-host GET look structurally similar. Multiple hosts, a .txt name, a 200, or a 206 cannot establish execution, maliciousness or compromise. Request endpoint file creation/process events for saving/execution and browser history for prior navigation. Record only that the network response body was visible. TLS decryption, real endpoint logs and browser behavior are outside this finite plaintext exercise.
