# Correlate RPC and service-related traffic

This complete supplemental Academy lab accompanies Stage 17 Lesson 4. The saved lesson demonstrates a method with no case file. This package adds a separate, real loopback capture of an inert mock SCMR responder. It preserves the lesson's limits: service queries, start requests, installation and process execution are different claims. No operating-system service was created, started or queried by the responder. Do not interpret its simulated state as a real service state.

Start with setup.md, complete worksheet.md and rpc-service-evidence-chain.csv, then compare answer-guide.md. DATA_DICTIONARY.md explains every supplied evidence class. practice.pcap is the unchanged tcpdump original; rpc-service-synthetic.pcapng is its lossless editcap conversion used in the exercises. The original frame numbers, packet bytes and timestamps are preserved. expected-results.json and decoded-fields.csv bind the worked answers to the delivered capture. collection.json records the actual lab collection; collect_rpc_lab.py is its inert client/responder source. No external target or credentials are involved.

The host-event-comparison-synthetic.csv rows are authored hypothetical 4697/4688 records for an identity/clock comparison exercise. They are NOT a Windows audit export, not captured host events, and cannot corroborate the real loopback packets. Real target-host service/process records remain a follow-up requirement when investigating a real environment. The kit does not claim to supply the absent original case, perform a learner's own capture, or prove Windows 11 command execution.

The optional collection program requires administrator capture privilege, tcpdump and Impacket 0.13.0. Analysis and the verifier require Python 3.10+ and TShark 4.4.0; no Impacket, administrator privilege or live network access is required for the delivered file exercise. Fresh collections are new evidence with nondeterministic times, IDs and packet totals; they never replace the delivered worked-answer identity.
