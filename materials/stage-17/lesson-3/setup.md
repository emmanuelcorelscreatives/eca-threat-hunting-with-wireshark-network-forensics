# Setup and reproducible workflow

Use an offline working directory and Wireshark 4.4 with TShark and Capinfos. The new fixture is a synthetic SMB 2.0.2 protocol model. Its accepted sessions have empty security tokens; do not interpret them as realistic authentication or identity evidence. No live server, administrator privileges, network access or credentials are needed.

1. Retain the original PCAPNG. Verify its hash with `sha256sum admin-share-training.pcapng` on Linux or `Get-FileHash .\admin-share-training.pcapng -Algorithm SHA256` in Windows PowerShell. The Linux command was executed; the Windows alternative is learner guidance, not an execution receipt.
2. Run `capinfos -c -a -e -u -I admin-share-training.pcapng`. Compare the manifest's 30 frames, time bounds and synthetic interface. Read execution.json for actual command arguments/platform and the paired stdout/stderr files for outputs. Absolute paths in receipts are provenance, not learner paths.
3. Wireshark File → Open your working copy. Record source, hash, peer roles, time span, observation point, both-direction coverage, session starts and ends. All30 frames are authored; absence of gaps in this fixture says nothing about unseen real activity.
4. Apply `smb2`. There are18 messages. Statistics → Conversations → TCP shows the two peer conversations. Select Limit to display filter if you want its counters restricted to SMB2 packets. Keep the checkbox state with any counts. Full conversations contain12 comparison and18 candidate frames; SMB2-only views contain6 and 12 respectively. Conversation bytes are protocol overhead plus data, not artifact size.
5. Apply `ip.addr == 192.0.2.10 && ip.addr == 198.51.100.20` for both candidate directions. Use `smb2.tree contains "ADMIN$"` to locate share references, then return to the pair view; a tree filter is not a complete file-operation sequence.
6. Select original frames 20–27. Expand SMB2 details and pair request/reply message IDs within the TCP stream. Track tree 90, session 900 and the CREATE response file ID into WRITE/CLOSE. Use frame 24 data bytes and frame 25 returned write count. The detailed CLI output supports an independent comparison.
7. Rebuild locally with `python3 offline-builder.py rebuilt.pcapng`. It refuses any existing output. Compare SHA256 with the original. builder-execution.json records an actual exact-byte rebuild and overwrite refusal. Do not edit the original to force a match.

Command reproduction: `tshark -r admin-share-training.pcapng -Y smb2 -V` and `tshark -r admin-share-training.pcapng -Y 'smb2.tree contains "ADMIN$"' -T fields -e frame.number -e smb2.tree` (single quotes are shell grouping on Linux; use appropriate quoting on Windows).
