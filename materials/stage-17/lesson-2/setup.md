# Setup and loading

Install Wireshark and its command line tools using your operating system's trusted package source. On Ubuntu, `sudo apt install wireshark tshark` supplies Wireshark, TShark, capinfos and editcap. Windows learners can install the Wireshark desktop package and its command line tools; no live capture driver is required for this offline exercise. Windows installation and GUI steps are instructions, not an executed Windows test.

Extract the complete ZIP into a writable folder. Retain an untouched original and open a working copy of practice.pcap. Before inspecting packets, record filename, SHA256, provenance, capture interface and time coverage in capture-notes-template.md. Run `python3 check_capture.py .` in the extracted folder (Python3 and TShark on PATH). This checks both exact published captures and their request/response relationships; it is not a generic verdict on an arbitrary capture. Use `sha256sum practice.pcap window-ended.pcapng` on Linux or `Get-FileHash practice.pcap -Algorithm SHA256` in PowerShell to compare fixture-spec.json.

The lab uses nonstandard TCP port 17452. In Wireshark select a packet in the connection, choose Analyze → Decode As, select TCP port 17452, and choose NBSS (NetBIOS Session Service). Apply the change, then filter `smb2`. Command line equivalent: `tshark -r practice.pcap -d tcp.port==17452,nbss -Y smb2`. If no SMB2 appears, check Decode As rather than declaring SMB absent. Native default decoding without this mapping is not sufficient. For times, select View → Time Display Format → UTC Date and Time of Day and record that display choice.

Optional rebuild on a disposable Linux host only: create a new Python venv, install requirements.txt, and run `sudo /absolute/path/to/venv/bin/python collect_lab.py NEW_OUTPUT_DIRECTORY`. It needs tcpdump and permission to capture lo and bind only 127.0.0.1:17452. The destination must not exist and the port must be free. The collector creates a temporary share, performs only the included seed read and upload, validates their bytes, stops its own server and tcpdump, and removes the temporary share. It does not read user files or listen externally. Captures have fresh clock, random IDs and source port, so they will not match the published hashes or fixed frame references; inspect them separately. Never overwrite this approved fixture or spec to make a checker pass. Impacket 0.13.1 was used for the actual collection; requirements.txt pins its direct dependency, not every transitive wheel. Rebuild requires network access to obtain that tool; the supplied offline exercise does not.
