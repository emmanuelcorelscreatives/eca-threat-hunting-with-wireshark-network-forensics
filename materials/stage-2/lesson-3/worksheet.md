# Worksheet — Create Your Threat Hunting Profile

**Hypothesis to test:** A colleague using the same input file and documented settings can reproduce the viewing choices. Agreement would not establish what the traffic means. Use the Academy’s published synthetic `practice.pcap` for this supplemental check; an authorized case handoff must identify its own authorized capture.

1. In Wireshark, choose **Edit → Configuration Profiles**. Create and activate **Hunt Workspace**, leaving Default unchanged. Record installed version and operating system: ____; active profile: ____.
2. Under **Edit → Preferences → Appearance → Columns**, set this order: **No.** (Number), **Time** (Time), **Source** (Source), **Destination** (Destination), **Protocol** (Protocol), **Length** (Length), **TCP Stream** (Custom field `tcp.stream`), **Info** (Information). Keep Info readable. Record the actual title, type, and—especially for the custom column—field of each: ____. A non-TCP row may have no TCP Stream value.
3. Disable **network-address resolution** for this offline view; record its state: ____. Choose **View → Time Display Format → Date and Time of Day** and leave timestamp precision **Automatic**. Record both choices and the viewing computer’s time zone: ____. The profile does not set the operating system’s time zone.
4. In **View → Coloring Rules**, save and enable, in this order: **TCP 443** — `tcp.port == 443`, light blue background (suggested `#D9EAF7`); **Other TCP** — `tcp`, pale gray background (suggested `#ECEFF1`). Use legible text and record the actual colors: ____. Check the specific rule is first. A temporary conversation color is not a substitute.
5. In **Analyze → Display Filters**, save **TCP only** — `tcp` and **DNS only** — `dns`. Check each name and expression in the toolbar bookmark menu. These are separate starting views, not detections.
6. Open the published offline `practice.pcap`. Record the input filename and location: ____. Select **TCP only**, apply it, and record the toolbar expression and protocol/field values you actually inspect: ____. What remains in the file but is hidden by this view? ____. Clear the filter and check that the saved bookmark remains. Do not infer activity outside the capture from an empty view or a colored row.
7. Return to **Configuration Profiles** and export the selected personal profile as a ZIP through your approved channel. Record its filename: ____. Have a second analyst import and select it, addressing any same-name conflict explicitly. Compare the version, same input file, column definitions, address resolution, time format, precision, time zone, ordered rules, saved expressions, and active filter. Record differences rather than treating them as findings: ____.

**Handoff assessment:** Which setting or packet field supports reproducibility? ____; what else could explain a different view (including input file, version, time zone, resolution, filter, or rule order)? ____; confidence limit: ____; next useful action: ____. A profile ZIP is not the capture. The next lesson considers where a capture comes from.
