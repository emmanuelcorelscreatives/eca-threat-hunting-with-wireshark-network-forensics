# Hunt Workspace — setup

This supplemental Academy exercise teaches the unchanged lesson's full profile and handoff workflow. It supplies a synthetic 10-frame offline capture, an offline builder, a real native profile ZIP, and source-bound Linux GUI observations. It does not replace the narration's unspecified authorized capture or claim a learner performed a capture. No live collection is required.

Download this whole directory together. Open `practice.pcap` directly in an approved Wireshark installation. The source lesson demonstrates Wireshark 4.6.9 on Windows 11; our separate validation ran source-built 4.6.9 on Ubuntu 24.04 for profile settings and installed 4.2.2 on Ubuntu for native ZIP export/import. Check your installed menu wording and version. `profile-transfer-execution.json` records those boundaries and the UTC process zone. The operating system's timezone was not changed by importing the profile.

Follow `worksheet.md` to create Hunt Workspace yourself before using the supplied ZIP as a comparison. `Hunt-Workspace.zip` is a real native Wireshark 4.2.2 export, containing the named profile's preferences, coloring rules, display filters and recent viewing settings; it is not the capture. Its settings were loaded in a separate native recipient session. Native screenshots illustrate exact declared versions, not Windows 11.

For a transfer check use Edit → Configuration Profiles → Import → From Zip File, select the ZIP, then select Hunt Workspace and Apply/OK. Inspect the active profile status after import. In our recorded same-name check the app imported 0 profiles and skipped 1; it did not overwrite the existing profile. Resolve conflicts deliberately: retain or back up the existing personal profile and choose an approved distinct name before retrying. Do not delete a colleague's profile blindly. In a clean recipient session the app imported 1 profile. Compare every worksheet setting and the input capture hash. The source-built 4.6.9 Linux binary used here has no Export control because it lacks minizip support; the separate installed 4.2.2 build supplies native Export/Import. Use an approved ZIP-capable build for that step, or explicitly record the missing capability rather than claiming export occurred.

Optional Python 3 regeneration sends no traffic. In this directory run `python3 offline-builder.py --spec fixture-spec.json --output rebuilt-practice.pcap`. Use a new output path: existing files are refused. On Windows an approved `py -3` can replace `python3`. The output is PCAP, not PCAPNG. Compare SHA-256 with `execution-proof.json` and the supplied `practice.pcap`. The Academy executed two exact byte rebuilds and an overwrite refusal; those observed runs do not claim execution on your machine.

Optional real TShark checks: `tshark -n -r practice.pcap -Y "tcp" -T fields -e frame.number -e tcp.stream` and `tshark -n -r practice.pcap -Y "dns" -T fields -e frame.number -e _ws.col.Protocol`. Exact Academy decoded fields and filter counts are in `decoded-fields.csv` and `execution-proof.json`. No TLS exchange, compromise finding or authorization evidence is supplied.
