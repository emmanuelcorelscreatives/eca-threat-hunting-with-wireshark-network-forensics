# Workstation capability worksheet

Use the downloadable blank CSV; keep raw tool output or errors verbatim, with a reference to your local transcript. Do not enter example versions or interfaces as machine observations.

1. State two hypotheses: **H1**, this user can display an authorized saved capture; **H2**, this user can start capture on the approved isolated adapter. Record OS, user context, installation choices, About details, and each tool result.
2. Record both interface lists and the specific adapter-identification basis. If identification is inconclusive, do not attempt H2.
3. Test H1 with an authorized file, or mark it pending if none exists. Test H2 only on the approved adapter; otherwise mark it unverified. Record exact observations, prompts, errors, and whether the short capture showed packets.
4. Report each status independently. For each, distinguish observation from inference, give a plausible alternative explanation, a confidence limit, and the next useful check. No packet filter, frame number, or traffic finding is required for this setup lesson.

**Decision practice—not workstation observations:** If a file opens but no approved adapter is identifiable, what are H1 and H2? If capture starts but the packet list stays empty, what has—and has not—been established? If TShark is not found, which installation or path checks come before a capture-permission conclusion?
