# Setup

## Included Downloadable Resources

- `worksheet.md` — narrative template, evidence-register schema and reviewer checklist.
- `answer-guide.md` — reasoning key and checkable pass conditions.
- `setup.md` — usage instructions.

These files are the complete set for this blank practice exercise. No shared prerequisite, capture or supporting record is required.

## Use in Windows 11 Notepad

1. Open `worksheet.md` in Notepad.
2. Enter answers only where the saved lesson context supports them.
3. Mark unavailable case values explicitly and save the draft.
4. Compare it with `answer-guide.md`; revise any unsupported statement.

**Expected result:** A reviewable draft whose case-specific fields remain unresolved and whose checklist can be completed without claiming packet analysis or findings.

The optional `practice/dns-baseline/README.md` six-packet synthetic DNS fixture is not used for this exercise and must not be treated as Project 7 evidence. It establishes neither compromise nor a later connection.
