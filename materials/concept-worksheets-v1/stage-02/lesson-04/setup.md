# Setup — Understand Where the Capture Comes From

**Status:** Draft supporting artifact for separate review; not visual approval.

## Downloadable resources

Download and keep together:

- `setup.md` — instructions
- `worksheet.md` — printable exercise and blank evidence record
- `answer-guide.md` — conditional reasoning key

No other input or shared prerequisite is required. Do not supply a PCAP, private data, credentials, network access, or a production environment. Wireshark installation is not required.

## Use

1. Open `worksheet.md` in a Markdown viewer.
2. Treat every route and the topology as a synthetic teaching example, never observed traffic.
3. Treat T0–T1 as a symbolic hypothetical collection window, not actual timestamps.
4. Complete the blanks before comparing `answer-guide.md`.

> No case PCAP was supplied for this lesson so this screen shows where to check, not an observed result.

Wireshark references are menu guidance only; they provide no file properties, packets, counts, or findings.
