# Setup

## Downloadable resources
Keep these three UTF-8 Markdown files together:
- `setup.md` — usage and evidence limits.
- `worksheet.md` — blank working template.
- `answer-guide.md` — checkable structural results and reasoning.

No other file is required. This lesson is intentionally case-free: no capture, host-event excerpt, inventory, source, target, account, time window, or finding is supplied. An empty Wireshark packet list says nothing about activity.

Open a working copy of `worksheet.md` in a text editor. Retain blanks or bracketed placeholders for this exercise; do not fabricate case values. A later application must use authorized evidence and preserve source filenames, frame numbers, original timestamps, time zones, and record references.

Wireshark is optional for later authorized work. The `smb2` filter locates decoded SMB traffic; it does not establish intent, coverage, transfer, or execution. The verified `practice/dns-baseline` supplement is DNS-only and is not an input. No command execution or successful result is claimed.
