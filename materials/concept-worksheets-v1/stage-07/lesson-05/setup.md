# Setup and Resources

The downloadable resources are `setup.md`, `worksheet.md`, and `answer-guide.md`. They form a standalone concept exercise; no capture, inventory, schedule, or case finding is required.

The lesson's reference environment is English, light-theme Wireshark 4.4.0 on Windows 11. If an Academy-reviewed applied pack is later supplied, use separate authorized offline working copies and open each independently.

Use **Statistics > Capture File Properties**, **Statistics > Endpoints**, **Statistics > Conversations**, and **Statistics > I/O Graphs**. Record the displayed time zone and every filter or statistics setting; never guess a clock correction. Keep frame references separate by file.

The verified DNS supplement is not a paired like-for-like baseline and is not used here.
