# Setup and use

**Status:** Draft supplemental concept practice for Stage 1: Course Introduction. It is not incident evidence.

## Required downloads
- `setup.md`: scope and instructions.
- `worksheet.md`: learner activity.
- `answer-guide.md`: reasoning key and self-check.

No other input is required. No case file, capture, dataset, schema, loading procedure, observed packet result, screenshot, or control total applies. The verified DNS baseline supplement is not used and supplies no facts here.

## Prerequisites and safety
Know basic networking and have opened a capture before. Use a Markdown viewer or repository web interface. Do not open a capture, connect to a live or production network, or use private traffic, credentials, or malware. No Wireshark procedure or command execution is required.

## Workflow
1. Read each explicitly synthetic condition.
2. Separate observation from hypotheses and unsupported claims.
3. Record a limitation, unknown, and authorized next check.
4. Write a bounded conclusion; unresolved is valid.
5. Compare your reasoning with `answer-guide.md`.

Every factual statement must trace to its prompt, and every explanation must be labelled as a hypothesis. These drafts require review before visual, PDF, or versioned publication.
