# Evidence reasoning worksheet

**Supplemental concept practice—no case file or packet findings.**

These source-derived prompts are **synthetic exercises**, not captured incidents or observed results. Treat only each condition as supplied hypothetical information. Do not invent addresses, identities, timestamps, packet counts, software, intent, or outcomes. Label explanations as hypotheses. If the evidence cannot answer something, write **unknown**. A bounded conclusion should include the observation, plausible explanation, evidence limit, remaining unknown, and authorized next check or unresolved status.
