# Lesson 6: materials and use

Download all three Markdown files supplied with this lesson: `setup.md` (instructions), `worksheet.md` (reusable record and exercise), and `answer-guide.md` (reasoning key). A UTF-8 Markdown viewer or editor is sufficient. Keep the master worksheet blank; complete a copy before reading the guide.

This is a workflow orientation, not a packet investigation. No case brief, capture, Wireshark installation, or shared dataset is required. The existing synthetic DNS supplement at `practice/dns-baseline/README.md` is not used here.

For a later investigation, start a fresh worksheet only with that case’s course-supplied authorized brief, capture, observation point, collection window, time zone, supporting records, and setup instructions. Do not substitute private traffic or invent missing course materials.
