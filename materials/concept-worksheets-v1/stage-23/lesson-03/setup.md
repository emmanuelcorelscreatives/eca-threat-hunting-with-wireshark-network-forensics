# Setup and resources

This is a no-install, no-dataset exercise. The conditional example is not a course-capture finding. Use the supplied premise or an authorized observation already investigated; leave unsupported evidence blank. Never enter private production data or credentials.

## Downloadable resources

- `setup.md` — prerequisites and workflow.
- `worksheet.md` — fillable exercise, field dictionary, and non-executable pseudocode.
- `answer-guide.md` — reasoning key and manual pass rubric.

Prerequisite: a Markdown viewer or editor. No capture, connection log, Zeek installation, security platform, or credentials are required. Zeek `conn.log` is illustrative, not assumed deployed. The DNS baseline supplement is not an input and must not be used to infer recurrence, compromise, or another connection.

## Workflow

1. Save a working copy of `worksheet.md`.
2. Complete facts and limits before proposing conditions.
3. Retain named placeholders where evidence supplies no value.
4. Compare the draft with `answer-guide.md`.

There are no commands, automated tests, or measured results. Review is manual.
