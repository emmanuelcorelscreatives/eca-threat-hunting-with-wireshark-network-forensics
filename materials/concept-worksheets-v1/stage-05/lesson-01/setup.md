# Setup and Downloadable Resources

Download these three draft companion files into one folder:

- `setup.md` — requirements and use instructions.
- `worksheet.md` — questions and a blank evidence note.
- `answer-guide.md` — checkable conceptual reasoning.

No packet file or capture is supplied with this worksheet. No dataset, network access, credentials, or software installation is required. The verified DNS baseline supplement is not a prerequisite and is not used. These exercises are conceptual; they are not an incident, case record, or observation of traffic.

## Use

1. Read the worksheet and answer without opening or creating a capture.
2. Leave unavailable evidence fields as `unknown` or `not examined`.
3. Compare your reasoning with the answer guide and revise unsupported conclusions.

> This walkthrough shows only the control; it does not claim a collection occurred.
