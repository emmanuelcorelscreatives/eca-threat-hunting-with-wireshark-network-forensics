# Data dictionary and limits

`practice.pcap`: preserved 37-frame synthetic IPv4 Ethernet PCAP. `fixture-spec.synthetic.json`: exact consumed version1 synthetic event specification; Python builder reads this data without execution. `offline-builder.py`: deterministic offline generator, standard library only, documentation IPv4 addresses only; exclusive output creation preserves existing files. It creates DNS, TCP and UDP events for this fixture. `ipv6-builder.py`: separate fixed three-event documentation IPv6/UDP generator with calculated IPv6 UDP pseudo-header checksums; no TLS or live sockets. `ipv6-practice.pcap`: independent comparison capture.

`host-roles.synthetic.csv` and `ipv6-host-roles.synthetic.csv`: address, scenario_role and context_status. These are authored unverified hints, not operational identity evidence. `expected-results.json`: actual mechanical observations plus limits; file hashes bind exact captures. `execution-receipts.json`: exact command arguments, platform, return codes and named output files; refusals are intentional nonzero exits preserving original bytes. `frame-measurements.stdout.txt`: tab-separated packet records with header, relative time, frame sizes, addresses, stream, payload length, relative/raw sequence, retransmission and checksum status. Empty fields mean absent/unavailable, not zero. TShark checksum status1 is Good and status2 Unverified. `ipv6-packet-check.stdout.txt` provides tuple and checksum observations. Statistics stdout gives directions and durations; payload bytes differ from frame bytes and filesystem PCAP length.

`frame.len` is original frame size; `frame.cap_len` is available captured frame size. `tcp.len` reports segment payload length from headers; truncation can leave payload unavailable. Repeated sequence space can duplicate observed payload. TCP stream numbers are dissector-local grouping, not application identity. Start is relative to file start; Duration is first-to-last observed packet. `native-gui-receipt.json` binds actual raw screenshots to the IPv4 PCAP and platform. Screenshots show only visible fields, not unseen menu actions or a complete GUI automation certificate. Current inventory is a nonrecursive envelope: it lists every delivered member except itself. No historical incident, protected content, collector health, missing path coverage, process identity, role legitimacy or completed learner assignment is asserted.
