# Data dictionary

All records are fictitious Academy-authored scenario metadata dated 2025-02-03 UTC. They are **not packet-derived**, Windows exports, process logs, or evidence from the saved lecture. This is an independent lesson example, not a shared cross-lesson dataset. An empty CSV field means unavailable in this scenario, not evidence that an event did not occur. IDs are exercise references, never frame numbers. Addresses are documentation-only IPv4 ranges; workstation labels are synthetic names, not DNS lookups.

`synthetic_auth_exchanges.csv`: `exchange_id` is the unique modelled exchange; `request_utc`/`response_utc` are authored UTC times; `src_ip`/`dst_ip` are modelled network endpoints; `service` is KDC, LDAP, or SMB scenario context; `protocol` names the authentication protocol; `account` is an illustrative identifier; `account_basis` is `visible_model` when the scenario models an identifier in the request or `scenario_only` when it assigns one outside that request; `request_kind`/`response_kind` identify modelled operations; `result_code` belongs to that row’s protocol and is empty for an unseen outcome; `modelled_request_resends` and `repeat_time_utc` describe an unverified, authored duplicate-request hypothesis. No ports, TCP sequence numbers, packet counts, or actual connection boundaries are supplied.

`synthetic_identity_events.csv`: `event_id` is a row key; `event_utc` is UTC; `event_id_windows` is the modelled Windows event type; `account`, `client_address`, and `source_workstation` are scenario event fields; `status_code` and `status_label` belong to that event type. A 4771 client address can be translated. A 4776 source workstation is **not** its destination computer, and an empty client address supplies no IP mapping.

`synthetic_change_records.csv`: `record_id` identifies a hypothetical record; `event_utc`, `record_kind`, `account`, `host_ip`, `approved_source_ip`, `approved_destinations` (pipe-separated), `owner_group`, and `record_note` describe its recorded scope. A record is not independent confirmation that a configuration was effective.

`synthetic_environment_map.csv`: `ip`, `role`, `known_workstation`, and `authorization_note` are authored inventory assertions for this exercise. Blank workstation mappings are unresolved. In particular, the shared egress has no verified originating host. Match rows by account, compatible source information, and nearby UTC times; never join solely on time or equate Kerberos packet numbers with Windows event statuses.
