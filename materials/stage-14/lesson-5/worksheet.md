# Boundary investigation worksheet

Record learner name/date, capture filename/hash, capture point, time range, direction coverage, tool version and profile/key state. Keep every entry labeled observation, inference, unknown or design property. Capture scope is part of every claim.

1. State the limited hypothesis: can this authorized file distinguish HTTP/2 from QUIC and HTTP/3, and can it support more than one exchange per connection? Name evidence that could falsify or limit it.
2. Make six rows: http2, quic and http3, each before and after keys. Columns: filter, matching original frame numbers, direction (use transport ports because IPs are both loopback), exact field/value, client offer, verified server selection, decoded application, stream IDs, warning and remaining uncertainty. Leave protected application cells unknown before keys. An empty filter is not proof of absence.
3. Inspect visible ClientHello ALPN and any decrypted selected ALPN. Cite exact frames and fields. Distinguish offers from selected application, and distinguish QUIC Initial handshake clues from later protected stream payload. Cross-check application-execution.json only as a separate application receipt, not as packet observation.
4. In TCP stream 0, find HTTP/2 streams 1 and 3. Match each request path to a status and DATA/end-stream evidence in the server direction. Explain why HTTP/2 stream 0 is not a third request. Record which frame contains multiple streams and why counting packets or TCP connections undercounts exchanges.
5. In UDP conversation 0, inspect the decoded HTTP/3 requests and responses on QUIC streams 0 and 4. Separate these from unidirectional control/QPACK streams. Record paths, status, DATA and FIN evidence, and distinguish a complete observed lab exchange from a partially decoded protocol label.
6. Compare the same capture before/after secrets. What changed in your view? What remains outside the capture even now? Discuss local capture completeness, offload checksums, host/process identity beyond application receipts, internet sites and historical incident attribution.
7. Independent hypothetical Q0 is not in this capture: a UDP conversation is labeled QUIC, but opening packets, secrets and decoded HTTP/3 fields are unavailable. Give at least three competing explanations, the strongest justified statement, confidence limit, missing telemetry and smallest next action. Do not invent an IP, frame, path or selected protocol for Q0.
8. Write a short report with hypothesis, scope/hash, exact filters and field/frame/direction evidence, conclusion, strongest alternative, confidence and next action. Explicitly distinguish observation from inference and unknown.

Separate authorized-file assignment: with permission, use your own capture and matching session secrets supplied by its owner. Repeat the worksheet. If secrets or opening packets are unavailable, submit the bounded unknown and exact missing telemetry; do not claim this Academy capture is your own collection. Never obtain or expose another person's secrets. The assignment is enabled by the method, not asserted as already completed.
