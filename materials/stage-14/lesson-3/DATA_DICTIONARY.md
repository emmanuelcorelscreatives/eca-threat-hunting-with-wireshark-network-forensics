# Data dictionary

The case note is Academy scenario metadata reconciled against executed dissection. Frame numbers are original 1-based capture indices. `tcp.stream` is TShark/Wireshark assigned stream index. UTC times describe serialized synthetic record timestamps. Endpoints use reserved documentation addresses; the hostname uses `.test`. PCAPNG is binary packet transport with no embedded decryption secrets. The separate NSS-compatible key log matches only these generated TLS records. Its hash binds the exact disposable public lab secrets without printing values in guides. HTTP fields after decryption come from packet dissection, not packet-list expectation. Output hashes and executed argv in `verification.json` bind CLI results. Screenshots are actual Linux native UI and have only their documented narrow roles. Nothing here identifies a real person, device, process or historical incident.
