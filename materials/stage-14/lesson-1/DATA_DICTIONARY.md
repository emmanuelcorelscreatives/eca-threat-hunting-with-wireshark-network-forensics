# Data dictionary and provenance

`fixtures/tls13-visible-handshake-supplemental.pcapng`: actual immutable OpenSSL TLS1.3 loopback capture; private material destroyed. `collection-receipt.json` records generated local test provenance and real OS. This is supplemental coursework, not the unsupplied historical walkthrough capture.

`hello-fields.tsv`: tab-separated header then original frame, epoch timestamp, source/destination IP and ports, actual TCP stream, handshake type, legacy version, supported-version extension and cipher-suite values; comma-separated values occur when a packet contains several fields. `opaque-records.tsv`: original frames with outer TLS1.3 opaque type23, stream and one value per decoded record. `outer-records.tsv`: original proposed content-type filter with header and zero data rows, intentionally retained. `all-frames.tsv`: relative time, endpoints, stream, relative TCP sequence/acknowledgment, TCP payload length, flags and nonopaque content types. `decoded-packets.txt`: actual verbose TShark decoding, including TLS record details. Blank fields mean no value decoded by that requested field, not proof of no protocol traffic.

`capinfos.txt`: actual metadata including filesystem and packet-byte counts, time range, interface and collector version. `cli-execution.json` and `opaque-records-execution.json` bind executed commands to outputs; absolute paths record Academy's execution location. `native-receipt*.json` bind actual native screenshots to capture bytes; they grant no video approval or broader GUI action proof. `example-cards.csv` is hypothetical and separate from observed data. `current-kit-inventory.json` hashes every other shipped member; its own SHA is carried in the independent review/publication receipt to avoid recursive self hashing.

`verify-fixture.sh` executes the Python verifier. Its checks establish fixed capture identity and repeat key field observations, not maliciousness, complete capture or decrypted application content. The kit is self-contained for offline reading; the locally installed tools are prerequisites for repeated execution.
