# Field and evidence dictionary

frame.number is local to one capture and changes when a prior record is removed. frame.time_relative is seconds since that file's first frame. The fixture uses UTC timestamps; displayed time depends on your Wireshark setting. ip.src/dst indicate observed packet direction at the simulated capture point. tcp.srcport/dstport plus both IP addresses distinguish these designed connections. tcp.stream is a dissector grouping index, not a process identity. tcp.flags provides SYN, ACK and FIN context; tcp.len counts TCP payload bytes. frame.len is original frame length; frame.cap_len is the bytes saved in that record. These differ from filesystem size and application body size.

Conversation counters total observed frame bytes, including headers and acknowledgments; they do not measure unique application content. HTTP request URI/response code are visible only where sufficiently captured and dissected. The baseline response has a 4-byte DEMO body, but a 42-byte HTTP message and a 96-byte Ethernet frame. UDP datagrams have no TCP connection. Graph bins count their configured packets or bytes, not application requests. Missing observations do not identify a real loss mechanism.
