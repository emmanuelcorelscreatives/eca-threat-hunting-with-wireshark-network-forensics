# Setup and use

Download `setup.md`, `worksheet.md`, and `answer-guide.md` before use. Open them in a UTF-8 Markdown viewer or editor. These are draft contents, not a claim that files have been published in the course repository.

This is a writing exercise, not another hunt. No capture, shared dataset, credentials, Wireshark session, or Project 7 file is supplied or required. For a real handoff, use only evidence already available from the completed, authorized investigation. Do not turn the optional DNS baseline fixture into evidence for this case.

**Field dictionary:** Capture identity names the original authorized file; packet references identify packets *within that file*. Capture window and observation point bound coverage. Asset mapping links an observed address to a verified asset; an address alone does not establish ownership. Evidence status distinguishes confirmed preservation from pending checks.

Complete the blank worksheet only with verified facts. Then do the separate synthetic wording exercise and compare your answers with the guide. Leave unavailable facts marked pending rather than inventing them.
