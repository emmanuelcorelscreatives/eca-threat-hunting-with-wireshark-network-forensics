# Setup and field dictionary

**Required downloads:** `setup.md`, `worksheet.md`, and `answer-guide.md`, supplied together as draft supporting files. Open them locally with any text or Markdown viewer/editor. No capture, credentials, network access, code, or other course file is required. These drafts are not claimed to be published in the public repository.

**Synthetic no-capture exercise:** Complete `worksheet.md` without loading a capture, then check `answer-guide.md`. An empty Wireshark view supplies no packet measurements. Write `not supplied` for missing source material, `unknown` for unavailable context or comparisons, and `Not established` for unsupported claims—not zero traffic.

| Field | Entry rule |
|---|---|
| Capture/source | Identify the actual source, collection point, window, and visibility. If using a working copy, map its frames to the original. |
| Evidence row | Identify the source and exact filter or pivot. Cite original frames only when packets exist; record graph intervals or conversation groupings if used. |
| Status | `Observed`: visible packets or supplied records. `Inferred`: possible meaning alongside an alternative. `Not established`: evidence cannot support the claim. |
| Context/control | Cite an authorized inventory or owner record and a comparable role/time control, or write `unknown`. |
| Disposition | Choose `suspicious`, `explained`, or `unresolved`; give a reason and the strongest available counterpoint. |
| Confidence/request | Assess occurrence separately from purpose; name one missing item, its provider, and how it could change the decision. |
