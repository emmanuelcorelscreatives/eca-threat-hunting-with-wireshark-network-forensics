# Connect entry, callback and internal activity — separate Academy lab

This complete synthetic exercise supplements Stage 20 Lesson 2. The saved demonstration has no supplied historical case capture or host excerpt; that remains true. These generated packets and records are teaching data, not an incident, actual network collection, or proof of compromise. All addresses are documentation ranges. No network traffic is generated by the builder.

Start with setup.md, complete worksheet.md, then compare answer-guide.md. Three separate classic Ethernet PCAP files preserve their own original frame numbers. Do not merge them as original evidence. The kit includes actual capinfos, TShark fields and conversation command outputs, the offline builder, an independent raw-record checker, its execution report and safety tests. Those are CLI evidence, not recordings of Windows GUI actions. Student GUI tasks below remain actions for the learner to perform.

Sensor model: delivery.pcap is a synthetic workstation-facing observation of an HTTP exchange; outbound.pcap models egress from that workstation; internal.pcap models an internal workstation-to-server path. Each starts with a SYN and includes both directions. Each is only its listed packets, not continuous sensor coverage. Classic PCAP has no interface-name metadata. UTC epoch timestamps have a stipulated ±2 second sensor uncertainty. Keep original times and do not apply an unjustified offset. Viewing time zones may differ. End-of-file does not prove activity ended.

corroborating-records.csv contains six synthetic excerpts. Every row has its original time basis, validity interval, asset/address context, observation and limits. These stipulations support an exercise, not real host attribution. The updater peer and administration window are benign alternatives. There is no process-to-network, execution, identity authentication, command, or transfer evidence.

current-kit-inventory.json binds every other current member with SHA-256 and length and intentionally excludes its own recursive hash. Publication receipts separately bind that envelope.
