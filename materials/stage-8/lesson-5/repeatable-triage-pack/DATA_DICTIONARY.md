# Fields, paths and evidence boundaries

point-*.json are explicit version 1 synthetic event data for offline_builder.py. Each ordered TCP event records UTC timestamp, documentation IPv4 addresses, ports, flags, raw sequence/acknowledgment and UTF-8 payload. The builder supplies deterministic Ethernet addresses and source-local IPv4 IDs, checksums and PCAP records; it sends no traffic and refuses existing output. inputs/originals/*.pcap are delivered immutable originals. JSON is the complete implemented alternative to the earlier unimplemented CSV generator.

paths-manifest.csv supplies stable source_id, original_path, working_path and authored coverage metadata. evidence/source-log.json records observed file hashes/lengths alongside those declarations. capinfos outputs supply count, times, ordering, snaplen and available interface information. Missing collector-interface identity stays unknown. evidence/execution.json records exact argument arrays and stdout/stderr from actual builder, refusal, versions, capinfos, TShark selections, summaries, derivatives and CSV runs. Its local native binary path is historical execution provenance; learners use installed tshark/capinfos.

worked-results/ retains the complete author-run outputs and actual working/regenerated copies for comparison. results/ is absent until the learner creates it and is ignored by the kit's repository ignore rule. evidence/label-execution.json records the exact supplied labeling command and row-retention observation. native/ holds actual Linux GUI evidence; its receipt describes requested observation scope, never hidden pixels or broader scene approval.

CSV frame.number is original source-local frame number when exported directly from an unchanged working copy. Always pair it with source_id and original_input_filename. frame.time_epoch remains an exact string for storage and is sorted using Decimal arithmetic. frame.len is frame length, not unique transfer. ip.src/ip.dst represent the first occurrence in this export; IPv6 and richer repeated fields require explicitly extended exports. Labeled raw rows retain these values. Sorted order does not establish synchronized collector clocks, duplicate packets or a causal relationship.
