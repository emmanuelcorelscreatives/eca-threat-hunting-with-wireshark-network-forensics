# Build a repeatable three-source triage pack

This complete Academy-authored offline synthetic exercise supports Stage 8 Lesson 5. It is a new practice case, separate from the unavailable narrated incident. It sends no packets. The package contains three immutable PCAP originals, their JSON specifications, the offline builder, source manifest, executed CLI outputs, source-labeled CSV timeline, native Linux Wireshark screenshots, worksheets and a checked answer guide. Publication is a later release action; no remote checkout is needed for this local kit.

Start with setup.md, complete worksheet.md, then compare answer-guide.md. Keep source originals unchanged and outside results/. Worked outputs are in worked-results/; use a new results/ for your own work. All shipped results were executed on Ubuntu 24.04 with native Wireshark/TShark 4.4.0. There is no Windows execution claim. GUI screenshots record actual native views, not a drawing or a learner run. The screenshots require independent approval before release.

A new analyst should be able to check hashes, reproduce the commands, and locate every cited original frame. Completion can be inconclusive about the lead: contact does not establish process, intent, authorization, malicious purpose or unique transferred bytes.
