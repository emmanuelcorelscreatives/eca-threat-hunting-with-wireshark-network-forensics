# Summarize Endpoints and Conversations in Batches

This separate synthetic Academy lab practices the complete saved lesson workflow: three known offline files, separate intake and working-copy identities, installed versions and Default profile, per-file IPv4 Endpoints/TCP/UDP Conversations, explicit statistics filters, native GUI comparison, representative packets and cautious cross-source interpretation. It is not the unavailable narrated historical case.

Start with [setup.md](setup.md), complete [worksheet.md](worksheet.md), and compare with [answer-guide.md](answer-guide.md). The specs and offline builder send no packets. Three verified PCAPNG originals and byte-identical working copies are supplied; no external capture is needed for the worked practice. An authorized-file extension is included in the worksheet.

`execution-receipt.json` and `*.stdout.txt`/`*.stderr.txt` are actual read-only Linux command records. Paths in them identify the production validation directory, not a directory students must have. Commands in setup use local relative paths. `native-*.png` and `native-evidence.json` record the same working-copy bytes in native Linux Wireshark. Empty stderr files are retained. `current-kit-inventory.json` binds every delivered member except itself by SHA-256. Preserve the historical blank intake template `case-manifest.csv`; measured intake is in `verified-intake.csv`.

All timestamps, addresses, capture points and traffic are synthetic. Collection points/windows are authored scenario metadata, not measured link coverage. Frame bytes count captured frames, not unique application payload. Repeated rows cannot establish users, processes, malicious intent, independent network events or network-wide absence.
