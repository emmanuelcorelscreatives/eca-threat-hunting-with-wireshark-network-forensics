# Data dictionary

scenario.json is the preserved synthetic design schema academy-weak-indicator-design-v1, consumed by the delivered custom standard-library builder. It is not a fixtureSpec for the earlier documentation-network-only builder. roles maps client/resolver/candidate/possiblePeer/incidental to fixed offline packet addresses. authorizedWindowUtc has inclusive start and exclusive end. dnsDesign describes one question and one response with two A records; ttlSeconds is the answer TTL. sessionDesigns lists each distinct client-port transport conversation. packetPlan gives offsetMs, from, flags, raw seq/ack and optional exact ASCII payloadText. SYN and FIN each consume a sequence number; payload lengths are encoded bytes. The implementation serializes Ethernet, IPv4, UDP/DNS and TCP explicitly with real checksums; no live network interface is opened.

practice.pcap is classic little-endian microsecond PCAP with Ethernet linktype 1. Packet frame numbers and TShark tcp.stream values are observed decoded identifiers for this exact file, not scenario IDs. independent-pcap-report.json binds SHA-256, true filesystem bytes, frame groups and actual decoded rows. execution-proof.json and stdout/stderr logs record actual runs, byte-identical regeneration, refusal to overwrite and corrupted-input rejection. Native screenshots and their ledger, when supplied, show real Wireshark on an isolated Linux display and grant only their explicitly observed state, not a historical incident or learner collection claim. File size, packet byte totals and native Properties display accounting are different units; do not substitute one for another.

Missing telemetry: historical case, real alert, process ownership, agent baseline, NAT attribution, endpoint purpose and continuous sensor coverage. No data field supplies those facts.
