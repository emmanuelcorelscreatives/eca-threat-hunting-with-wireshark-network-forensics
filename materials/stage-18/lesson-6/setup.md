No network connection, credentials or additional dataset is required. Python 3 standard library and Wireshark/TShark/capinfos are needed. Production captures remain separate. From the extracted kit folder, inspect `execution-proof.json`, the two `*-decoded.stdout.txt` tables, `expected-results.json`, and `supporting-records.csv`. Open `observation-a-supplemental.pcapng` and `observation-b-supplemental.pcapng` separately in Wireshark. Select View → Time Display Format → UTC Date and Time of Day. Inspect Statistics → Capture File Properties and Statistics → Conversations → TCP. Apply the exact filters in `worksheet.md`, select cited frames in both directions and expand Internet Protocol and Transmission Control Protocol in Packet Details. The protocol tree proves only what is present; these packets contain no application payload. Clear the filter and verify the full count after each candidate.

For a safe local rebuild use fresh names that do not exist. Run from this folder:

```sh
python3 offline-pcap-builder.py --spec observation-a-spec.json --output rebuilt-a.pcap
python3 offline-pcap-builder.py --spec observation-b-spec.json --output rebuilt-b.pcap
tshark -r rebuilt-a.pcap -F pcapng -w rebuilt-a.pcapng
tshark -r rebuilt-b.pcap -F pcapng -w rebuilt-b.pcapng
capinfos -c -a -e -u rebuilt-a.pcapng rebuilt-b.pcapng
tshark -r rebuilt-a.pcapng -q -z conv,tcp
tshark -r rebuilt-b.pcapng -q -z conv,tcp
python3 -m json.tool expected-results.json
```

Builder output is exclusive: it refuses an existing destination. TShark conversion may overwrite its output; choose new filenames each time.
