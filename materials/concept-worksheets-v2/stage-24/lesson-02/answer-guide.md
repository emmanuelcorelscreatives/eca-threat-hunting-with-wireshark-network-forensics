# Answer Guide

No evidence values were supplied, so review structure and reasoning rather than findings. For the blank run, absent context is marked **not yet checked** or **not available** as appropriate; evidence rows remain unpopulated. Do not invent IDs, hashes, times, counts, paths, or conclusions.

## Reasoning Key

1. **Filters:** A read filter can exclude traffic when opening the file. A display filter hides packets from view. Neither belongs in the initial coverage check. A collection filter is different because excluded packets may never have been captured.
2. **Preservation:** A correct register gives each supplied original a stable ID, location, authorized purpose, checked SHA-256, and checker. Every working copy or changed file has its own ID and hash linked to its parent. The original remains untouched.
3. **Time coverage:** The brief and business context justify the question window. Packet bounds, documented collection period, and every supporting source occupy separate lanes. The overlap between the question window and relevant available coverage may support a limited check; uncovered time remains a gap and cannot establish that nothing happened. Overlap between source lanes invites comparison but does not by itself link their observations.
4. **Vantage point:** One endpoint or sensor cannot establish activity on an unseen path. Record the capture point as unknown when undocumented and request an authorized source from the relevant path rather than treating it as quiet.
5. **Targeted request:** No case-specific gap can be ranked in this blank exercise. When authorized context supports ranking, name the affected question, missing observation, specific record or collection detail, responsible case owner, and retention concern. Do not request every possible log.

## Checkable Expected Result

- Originals and derivatives are distinguishable and linked.
- Unknown or unavailable measurements are not recorded as zero.
- Captured and displayed counts remain separate.
- Time zone, precision, accuracy, and only measured offsets are recorded separately.
- Gaps describe missing coverage, not detected activity.
- The handoff contains only the register, justified provisional window, limits, and targeted requests—no conclusion about identity, internal access, compromise, or data loss.
