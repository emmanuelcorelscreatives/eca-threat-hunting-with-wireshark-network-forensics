# Learner prerequisite: Windows 11 and Wireshark 4.4.0

Use your authorized Windows 11 environment with Wireshark 4.4.0, English menus and a light theme. Confirm Help → About Wireshark, or in PowerShell run `& "C:\Program Files\Wireshark\tshark.exe" -v | Select-Object -First 1`. Record the actual result. Do not interpret this proposed learner command as an author-side Windows test.

Open only the supplied offline working copy. Do not choose a capture interface or start collecting traffic. Work in a fresh local directory, preserve the downloaded originals, and choose new names for comments and exports. Read setup.md for exact files and optional Python verification. If your menus differ, stop and record the version rather than guessing. Author evidence in this package uses Ubuntu 24.04.5 LTS and native Wireshark 4.4.0, with that platform explicitly labelled.
