Start with [setup.md](setup.md), then complete [worksheet.md](worksheet.md). Use the supplied unannotated [synthetic pcapng](lesson5-synthetic-offline.pcapng). Color helps notice, temporary marks help return, saved filters reuse expressions, and a checked pcapng packet comment records an observation with uncertainty. None establishes malicious intent. The complete directory also includes generation and verification programs, immutable author reference outputs, actual CLI logs and native author screenshots. These are separate from a learner's own authorized capture and cannot establish that learner task has already been completed.
