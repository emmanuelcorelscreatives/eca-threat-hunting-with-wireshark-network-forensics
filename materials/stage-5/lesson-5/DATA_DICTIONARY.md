# Synthetic fixture dictionary

`lesson5-fixture.json` is version-1 **data** for the supplied offline builder; it is not a packet capture. The actual output is Ethernet/IPv4 on a constructed link, with artificial UTC timestamps from `2025-01-16T12:00:00.000000Z` through `12:00:00.200000Z`. This interval is a design, not measured coverage. The event order is DNS A query and response, three TCP handshake packets, then one non-DNS UDP datagram. No application exchange follows the TCP handshake.

`timestamp` sets packet time; `src`/`dst` are documentation-only IPv4 addresses; `sport`/`dport` are transport ports. DNS events carry `name`, `transactionId`, and, for the response, `answer`. TCP events carry `flags`, `seq`, `ack`, and empty `payloadText`; SYN and SYN-ACK each consume one sequence number. The UDP `payloadText` is artificial teaching text, not a credential. In a decoded copy, inspect `frame.number` (copy-relative reference), `frame.time_epoch`, `ip.src`, `ip.dst`, `dns.qry.name`, and `dns.a` where present. `frame.comment` applies only after a packet comment is saved in pcapng.

The design uses `192.0.2.10` for a synthetic endpoint, `192.0.2.53` for a synthetic DNS endpoint, and `198.51.100.20` for the constructed answer and TCP destination. Those labels do not identify real hosts, processes, users, intent, or activity outside this file. DNS-to-TCP timing alone does not establish why a connection occurred. The earlier unpublished draft proposed `lesson5.invalid`; this completed supplemental lab formally uses `lesson5.academy.test`. This name is present in both actual DNS packets and is not a real-service claim. `executed-fixture-spec.json` is the schema actually consumed by `offline-builder.py`; `lesson5-fixture.json` is the teaching event description, not that builder command-line schema. The exact builder invocation is `python offline-builder.py --spec executed-fixture-spec.json --output NEW_PCAP_PATH`. It refuses an existing output. The unannotated pcapng is a deterministic conversion of the same six packet bodies and timestamps.
