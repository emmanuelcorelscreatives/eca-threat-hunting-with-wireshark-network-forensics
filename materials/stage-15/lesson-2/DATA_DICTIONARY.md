# Synthetic fixture dictionary

Both inputs are UTF-8 TSV with headers. `inventory.tsv` declares `host_id`, `src_ip`, authored `role` and `designation`, `group_id`, complete `group_suffix`, `resolver_ip`, simulated `observation_point`, and inclusive `window_start_utc`/exclusive `window_end_utc`. Roles and control designations are scenario metadata, **not packet-derived service ownership**.

`events.tsv` is one intended DNS message per row. `event_id` is a worksheet reference, **not a frame number**; `timestamp` is UTC; `host_id` and `group_id` reference inventory; `src_ip`, `dst_ip`, `src_port`, `dst_port` specify the UDP endpoints; `txid` is the decimal DNS transaction ID. `qr` is `Q` or `R`. `name` is the complete ASCII `.test` question, and `qtype` is `A`, `AAAA`, or `TXT`. `rcode` is `NOERROR` or `NXDOMAIN` for responses; `answer_type` and `answer_value` specify one A or TXT answer when present. `-` means not applicable or no captured answer; TXT values are innocuous synthetic text. All packet IPv4 addresses and A answers are documentation addresses.

Pair a response with a query using reversed IPs and UDP ports plus `txid`, case-normalized complete `name`, and `qtype`; require a later response timestamp. Count queries by host, assigned domain group, and the common half-open window. A distinct name is one case-normalized **complete** question name, regardless of repeats or type. Count responses separately. Split names at dots; record the maximum label's position from the left and ASCII-octet length separately from the dotted name's length or Wireshark's reported `dns.qry.name.len`. Each label must fit 63 octets; that is a protocol limit, not an alert threshold. An absent captured response is not a resolver-failure code.
A requests an IPv4 address; AAAA requests an IPv6 address; TXT requests text records. NOERROR reports successful DNS processing but may contain no answer; NXDOMAIN reports that the queried domain does not exist. Neither describes application intent.
